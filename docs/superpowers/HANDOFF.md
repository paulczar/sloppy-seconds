## Project

`sloppy-seconds` — a static, GitHub-content-driven directory of AI-assisted open-source
**replacements** for commercial/closed-source software: cleanroom rebuilds, functional clones,
"very similar" alternatives, and AI-assisted language ports. The repo *is* the database: one
`apps/<slug>.md` per project (Zod-validated frontmatter), Astro builds it to static pages,
GitHub Actions refreshes live GitHub stats into `stats/stats.json` and deploys to Pages.
